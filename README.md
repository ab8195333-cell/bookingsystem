# 🚀 Advanced Booking SaaS System (Laravel 11)

نظام حجوزات احترافي متكامل مصمم كمنصة اشتراكات (SaaS) لخدمة أصحاب المحلات والعيادات والمكاتب. يتميز النظام بعزل كامل للبيانات لضمان خصوصية كل مستخدم.

## ✨ الميزات الرئيسية:
* **نظام عزل البيانات (Multi-tenancy):** كل مستخدم يدير حجوزاته وعملائه بشكل مستقل تماماً.
* **إدارة مالية:** إمكانية تحديد أسعار الحجوزات ومتابعة إجمالي الأرباح لكل مستخدم.
* **تصدير التقارير:** إمكانية تصدير كافة بيانات الحجوزات إلى ملفات Excel بضغطة زر.
* **إدارة الحالات:** تتبع حالة الحجوزات (قيد الانتظار، مؤكد، ملغي) بواجهة عصرية.
* **إشعارات تلقائية:** نظام إرسال إيميلات للعملاء عند تأكيد الحجز.

## 🛠 التقنيات المستخدمة:
* **Backend:** Laravel 11
* **Database:** MySQL
* **Frontend:** Bootstrap 5 (Responsive Dashboard)
* **Tools:** Git, Laragon, SMTP Integration
