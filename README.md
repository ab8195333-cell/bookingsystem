# 🚀 Pro-Booking SaaS | نظام الحجوزات الذكي

نظام سحابي متكامل لإدارة الحجوزات والخدمات، مُطور باستخدام إطار العمل **Laravel** مع واجهات عصرية ومتجاوبة مصممة بـ **Bootstrap 5 RTL**. يتيح النظام إدارة العملاء، تتبع الإيرادات، توليد التقارير، مع توفير **طبقة حماية متقدمة** للعمليات الحساسة.

---

## ✨ المميزات والخصائص الرئيسية

* **لوحة تحكم ذكية وشاملة**: عرض الإحصائيات الحية (عدد الحجوزات، إجمالي المبالغ، والاشتراكات).
* **إدارة الحجوزات (CRUD)**: إضافة، عرض، تعديل، وحذف الحجوزات بكل سهولة.
* **🔒 أمان متقدم وعالي (Admin Password Verification)**:
  * عمليات **التعديل** و**الحذف** محمية بالكامل.
  * يطلب النظام إدخال كلمة مرور المدير الحالية (عبر نافذة تفاعلية مؤمنة) والتحقق منها باستخدام `Hash::check()` قبل تنفيذ أي إجراء خطير.
* **صلاحيات مستخدمين متعددة**: فصل تام بين صلاحيات المستخدم العادي وصلاحيات الأدمن (`admin`).
* **تقارير PDF**: إمكانية تحميل تقارير شاملة للحجوزات بصيغة PDF بضغطة زر.
* **تصميم متجاوب (RTL)**: واجهات عربية بالكامل مصممة بأحدث معايير التصميم باستخدام Bootstrap 5 و FontAwesome.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **Backend:** PHP 8.3 / Laravel 
* **Frontend:** Blade Templates, Bootstrap 5 (RTL), FontAwesome, Google Fonts (Cairo)
* **Database:** MySQL
* **Deployment:** Docker / Render / GitHub
